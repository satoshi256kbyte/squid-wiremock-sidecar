# M04実装タスク

## T01: Test Client依存追加

- Test Clientイメージへcurlを追加する
- 非rootユーザー実行を維持する

## T02: プロキシ通信実装

- `HTTP_PROXY`が未設定の場合に停止する
- API URLとパスを環境変数から組み立てる
- `curl --proxy`でリクエストを送信する
- HTTPステータスと本文を契約どおり出力する

## T03: 失敗契約実装

- curlの通信失敗を標準エラーへ診断出力する
- プロキシ未設定を終了コード78で通知する
- HTTPエラー時はリトライせずステータスと本文を出力する

## T04: Test Client統合スモークテスト

- ComposeのSquidとWireMockを起動する
- Test ClientをComposeネットワーク内で実行する
- 正常系のステータス、本文、WireMock受信履歴を確認する
- プロキシ未設定時の終了コードと直接通信防止を確認する
- Compose停止時に孤児コンテナを残さない

## T05: Spec Kit整合性とレビュー

- `spec.md`、`clarify.md`、`plan.md`、`tasks.md`、`analyze.md`を確認する
- M06のリトライ、バックオフ、タイムアウトが混入していないことを確認する
- 品質ゲート実行結果を記録する

## 完了条件

- [ ] T01からT05を完了している
- [ ] Proxy経由の正常系通信が成功する
- [ ] 出力契約と失敗契約を検証できる
- [ ] WireMock直接接続の実装がない
- [ ] M01〜M03の契約を維持している

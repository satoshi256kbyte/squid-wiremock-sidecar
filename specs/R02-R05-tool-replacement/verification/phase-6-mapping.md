## 4. 信号の検査

- `check` の行で信号を送るものは2件（番号29、30。`smoke_case_signal INT 130`、`smoke_case_signal TERM 143`）。
- 信号を送る本体は Python の `signal` で書かれている（`smoke_child_signal` の約949〜1011行。`import signal` は953行）。
- `kill -INT`、`kill -TERM` の字句は、m08 には無い（`grep -n -E 'kill -(INT|TERM)'` で0件）。
- `grep -n 'signal\.SIG'` で数えると4行（960、966、967、978行）。

## 5. 他のテストの本文を読む検査

- m08 には、自分や他のテストのファイルを `grep` や `sed` で読んで判定する検査は無い。
- 自分の入口（`$SELF`）は、`sh "$SELF"` で実行する検査（168〜184行）と、`M08_LIB_ONLY=1` で関数だけを読む検査（399行）に使う。
  どちらも本文の字句は読まないため、薄い入口にしても判定は変わらない。
- 残る `grep` は、実行結果（`results`、`out`、`report`）の検査で、対象は一時ディレクトリである。
